# Data Sources

All vendor and venue data in this directory is **sample data** created for
development and testing. It does not represent real businesses.

Replace with real, verified records before any public demo. Each real record
must include:

- `source_url` — the public page or message where the data was obtained
- `verified_on` — the date the information was last confirmed
- `confidence` — high / medium / low
- Explicit consent before storing any vendor's contact details
